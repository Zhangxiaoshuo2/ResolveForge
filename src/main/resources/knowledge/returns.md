# ResolveForge 演示退换货政策

## 普通商品七天无理由退货 {#seven-days}
这是虚构演示政策。普通实物商品自签收次日起七个自然日内可申请无理由退货，须保持商品完好、配件和赠品齐全且不影响二次销售。机械键盘、无线鼠标、显示器、USB 扩展坞和降噪耳机在本演示中属于普通实物商品；仍需判断是否拆用损坏、是否超过期限，不能只凭商品类别保证可退。未发货订单应优先适用取消退款条款。

## 不适用无理由退货的情形 {#exclusions}
定制商品、易腐生鲜、已兑换的数字商品不适用七天无理由退货。因买家使用不当造成损坏、缺失重要配件或已超过七天期限的普通商品，也不能直接套用无理由退货。商品质量问题仍可按质量问题条款咨询；不能推导为所有商品均可无条件退款。

## 质量问题退换货 {#quality}
签收次日起十五个自然日内发现非人为质量问题，可提交故障说明、商品照片或检测材料，审核确认质量问题后可申请退货或换货。发现故障不等于已确认质量责任，客服不得直接保证审核通过。超出该演示期限的保修、维修及延保规则，本知识库未规定。

## 退换货运费承担 {#shipping-fee}
普通商品无理由退货由买家承担寄回运费；审核确认属于商品质量问题、错发或漏发责任的退换补货，由商家承担合理的物流费用。是否属于质量或商家责任须有材料核实，不预先保证运费金额。退货寄件前应取得审核后的收件指引，不能凭空提供仓库地址。

## 退货寄回与验收 {#inspection}
退货申请审核通过后，按审核给出的收件指引寄回商品及全部配件赠品，保留寄件凭证和运单号。仓库收到退货后在两个工作日内进行验收；通过验收后才进入退款流程。咨询系统无法直接创建退货单，知识库也不提供具体退货地址。
