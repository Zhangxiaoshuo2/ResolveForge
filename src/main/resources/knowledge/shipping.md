# ResolveForge 演示发货时效政策

## 普通商品发货时效 {#dispatch}
这是虚构演示政策。非预售、库存充足的普通订单在支付成功后四十八小时内安排发货；发货指交给承运商并产生揽收记录，不等于已送达。备货中、缺货或预售需以订单另行约定为准；仅有订单 PAID 或 UNSHIPPED 状态不能证明具体库存条件。

## 超时未发货的咨询处理 {#late-dispatch}
超过普通商品约定发货时限仍未发货，可以申请核实库存及预计发货时间，也可以按未发货取消退款条款咨询。必须先核对订单状态和适用前提。演示业务使用固定的合成订单日期，不应假设每个订单始终处于正常时效内。演示政策没有超时发货的自动赔付规则。

## 预计送达与地址变更 {#eta}
物流预计送达时间以承运商最新轨迹为参考，知识库不承诺固定日期必达。未发货订单可申请核实能否更改收货地址；已发货需询问承运商处理条件，不能保证改址或拦截成功。本系统只提供咨询，不执行地址修改，也不读取或展示收货地址。
