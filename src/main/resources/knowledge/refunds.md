# ResolveForge 演示退款政策

## 已支付未发货退款 {#unshipped}
这是虚构演示政策，不代表任何真实电商平台规则。订单已支付且尚未交给承运商（PAID 或 UNSHIPPED），可以申请取消订单并原路全额退款；无需先退货。实际是否符合条件须查询当前用户的订单，不能只采信用户陈述。知识库仅存通用规则，不提供个人订单事实。

## 退款审核及到账时间 {#timing}
本演示政策规定：符合条件的退款申请在两个工作日内审核；审核通过并发起退款后，原支付渠道预计三个工作日内到账。工作日不含周末及法定节假日。这是演示处理时限，不是订单已经退款或资金已到账的证明；本系统仅提供咨询，不会发起或承诺已完成退款。

## 已发货取消与拦截 {#shipped}
已发货（SHIPPED）的订单不能按未发货订单直接取消。可申请物流拦截，但能否拦截需要核实，不能保证成功；拦截失败应按签收后退货条件申请。不得仅因运输较慢承诺立即退款。当前系统不执行取消、拦截或退款，仅说明演示规则。

## 退款金额与额外赔偿范围 {#amount}
符合条件且完成所需退货验收的退款，退还对应商品实际支付金额。运费按退换货运费条款另行判断。不支持声称所有情况均无条件全额退款；本知识库没有延迟赔偿金额、罚款、优惠券返还或额外补贴的规则，不能自行承诺。
