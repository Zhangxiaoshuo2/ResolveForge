## 限制与待解决问题

- 评测为小型人工开发集，无独立留出集或真实流量，不把 100% Recall 当作生产准确率。

- 实际 API 模型输出有随机性；单次引用和提示注入样例通过不代表全面防护或长期稳定。
- 未做文档重排模型、独立向量库、知识管理后台；当前小规模不需要。
- PostgreSQL 未实测。HITL、退款执行、任务恢复、Chatwoot、Multi-Agent、Skills 不在 P1；不自动进入 P2。
